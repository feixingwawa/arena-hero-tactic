## TL;DR
两轮 BugFix 修复了 Worker「远敌误撤退→探索横跳」与「探索半径无限外扩→跑飞阵亡」两大根因，经济闭环（探索→采集→回城）已在线验证打通，44/44 离线测试通过；当前被 Arena Hero **服务端 ProtocolError**（外部故障）阻塞线上验证，恢复后一键重启即可。

## 修复前症状（logs/agent.log 实证）
- `threat:count=2:near=0` 与 `count=0` 每 2 tick 交替 → 全员 `retreat` ↔ `explore` 横跳
- pop 长期卡 2、res 恒 0，**从未出现 harvest/deposit/spawn**

## 根因与修复

### 根因 1：远敌误触发全局撤退
- `roles.py` 用 `retreat_radius=4` 判定所有敌人（含距 Core 很远的视野敌人）
- **修复**：新增 `retreat_adjacent=1`（空货 Worker 仅贴身才撤）、`retreat_radius=3`（满货/近 Core 保护）；探索遇敌改为「垂直避让」，禁止 LEFT↔RIGHT 反向横跳

### 根因 2：探索半径无限外扩
- `r_now = max(r_plan, dist_core + 2)` → Worker 目标永远在「当前距离+2」，跑到距 Core 70-80 格，回城途中被击杀（pop 归 0 后经济永久停摆）
- **修复**：`r_now` 严格封顶 `explore_max_radius=32`；`dist_core > 36` 触发 `:recall` 回撤；环带内垂直轴螺旋扫掠
